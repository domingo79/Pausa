# ⌛ Timer Pausa

App web per gestire i tempi di pausa in classe, costruita con **Streamlit**.

---

## Funzionalità

- Seleziona una pausa da **5 minuti**, **10 minuti** o un tempo **personalizzato (1-60)**
- Barra di avanzamento con colori che cambiano man mano che il tempo scorre
  - Verde → Arancione → Rosso
- Tasto **Pausa / Riprendi** per bloccare il conto alla rovescia
- Suono di allarme al termine del timer
- Messaggio finale: **"PAUSA FINITA! Tornate in aula"**
